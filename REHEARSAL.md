# Rehearsal checklist — Blockchain (Topic #33)

**Before anything:** put real names, student IDs, group, course and date in `src/deck/ui.tsx` (`PRESENTERS`, `GROUP`) and rebuild. Every slide, divider and speaker note updates automatically.

## Setup
- [ ] Copy `dist/index.html` to the classroom PC (USB + email backup). One file, works offline.
- [ ] Open in Chrome/Edge → press **F** (fullscreen).
- [ ] Clicker test: one click = one step.
- [ ] **Presenter View (recommended):** connect the projector as an *extended* display. Open the deck on the laptop, press **P** — a second window opens with the live slide, the next click, the script and the timer. Drag the *main* window to the projector and press **F** there. Drive everything from the Presenter View window.
- [ ] No second screen? Press **N** for the script + timer instead.

## Keys
| Key | Action |
|---|---|
| Click / → / Space | Next step (finishes any running animation first) |
| ← | Back one step |
| **A** / **B** | Slide 11 only — mark the Professor's answer |
| R | Restart the current slide |
| **P** | Open Presenter View (second window) |
| **.** | Black screen on/off (PowerPoint-style) |
| N | Script + timer (turns red if you're >15 s behind the plan) |
| G / End | Overview / jump to the Thank-you screen |
